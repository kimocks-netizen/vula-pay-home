## Tech Stack

- Framework:    TanStack Start (SSR React meta-framework)
- Language:     TypeScript 5.8
- Styling:      Tailwind CSS v4 + tw-animate-css
- UI:           shadcn/ui (full Radix primitive set)
- State:        TanStack Query v5 (no Zustand)
- Routing:      TanStack Router (file-based, auto-generated)
- Forms:        React Hook Form + Zod
- Charts:       Recharts
- QR:           qrcode (native generation)
- Build:        Vite 8 + Bun + Nitro (SSR server)
- Auth:         Custom (lib/auth.tsx)
- Tooling:      ESLint + Prettier
- Platform:     Lovable.dev
